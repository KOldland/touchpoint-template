# Compliance Observability and Deterministic Testing (COM-05)

## Overview

Compliance evaluations are now observable and deterministic through:

- telemetry event emission per check
- hashed-input audit records
- alert signal generation for abnormal patterns
- golden fixture tests in CI

## Telemetry

Primary event:

- `compliance.check`

Payload fields:

- `trace_id`
- `variant_id`
- `schedule_id` (optional)
- `status` (`OK` / `WARN` / `FAIL`)
- `rule_ids_triggered`
- `latency_ms`
- `timestamp`

Emission path:

- `EventEmitter -> EventQueue -> RetryService -> TelemetrySink`

Telemetry sink stores bounded event history in option key:

- `kh_smma_telemetry_events`

## Audit

Each evaluation writes:

- `compliance.check` via `AuditLogger::record_event()`

Audit payload includes:

- `trace_id`
- `variant_id`
- `schedule_id`
- `input_hash` (SHA-256)
- `status`
- `rules_triggered`
- `suggested_edits`
- `timestamp`

Raw input text is not stored.

## Alerts

Generated by `ComplianceTelemetryService` based on rolling 100-check history:

- `alert.compliance_fail_spike`
  - Trigger: fail rate > 20% (window >= 20)
- `alert.compliance_warn_fail_ratio`
  - Trigger: fail/warn ratio > 1.25 (warn count >= 5)
- `alert.compliance_rule_anomaly`
  - Trigger: one rule contributes > 50% of fail events
- `alert.compliance_latency`
  - Trigger: single check latency > 50ms

## Deterministic Fixtures

Fixtures under:

- `tests/fixtures/compliance/compliance_pass.json`
- `tests/fixtures/compliance/compliance_warn.json`
- `tests/fixtures/compliance/compliance_fail.json`

These validate expected status and triggered rule IDs in stable CI mode.

## Tests

- `tests/Compliance/ComplianceEngineTest.php`
- `tests/Compliance/ComplianceWorkflowSmokeTest.php`

Key assertions:

- fixture status/rule output consistency
- compliance telemetry events emitted
- alert events emitted under threshold breaches
- workflow behavior:
  - WARN requires approval
  - FAIL blocks scheduling
  - OK schedules successfully

## CI

Workflow:

- `.github/workflows/smma-ci.yml`

- Compliance engine fixture tests
- Compliance workflow smoke test
